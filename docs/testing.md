# 验证记录

## 2026-10-31：首次本机试刷

样本数：**1 台日版 GR DIGITAL III**。机身版本：MAIN 2.50、BKUP 1.00、MONI 1.00、EXTD 1.18、CPU1 1.00。

| 检查 | 证据 | 结果 |
| --- | --- | --- |
| 本机原始 MAIN 与官方 GLAUNCH3 一致 | 逐字节比较和 SHA-256 | 通过 |
| 候选文件仅改变指定 4 字节 | 文件比较 | 通过 |
| 校验算法 | 分组累加与独立逐字节重算 | 通过 |
| 离线撤销修改 | 与官方 GLAUNCH3 完全相同 | 通过 |
| 同版本更新 | 机主执行 2.50 → 2.50 | 更新后自动重启 |
| 中文菜单 | 机主直接确认 | 显示中文 |
| 拍摄、回放、拍摄/设置菜单切换 | 机主直接确认 | 正常 |
| 普通电源键关机后重启 | 机主直接确认 | 中文保持 |
| 新增 RAW＋JPEG | 电脑读取存储卡目录 | 两组文件均存在 |
| 新 JPEG 可读性 | 完整解码 | 两张均为 3648×2736，解码通过 |
| 新 DNG 结构 | TIFF 标记及 DNGVersion 文件头检查 | 通过；未进行完整 RAW 开发 |
| 原有照片 | 路径、长度、修改时间对比 | 未变；不是逐文件内容哈希检查 |
| 收尾 | 电脑操作 | 移除卡上的升级文件并安全卸载 |

上述“机主直接确认”来自操作反馈，不冒充自动采集结果。本仓库没有提供中文菜单实拍图；离线字形渲染图也不能替代相机截图。

## 尚未测试

- 全部菜单、拍摄模式、特殊字符及语言相关布局。

- 通过相机刷回原版；目前验证的是电脑上的原版文件一致性。

一次成功不能证明所有日版 GRD3 都适用。请使用 [Issue 测试反馈模板](https://github.com/AIyj-cmd/ricoh-grd3-zh/issues/new?template=test-report.md) 提供版本组合与具体结果，避免发布序列号、校准参数或个人照片。

## 软件测试范围

CI 使用合成数据检查校验算法、文件头拒绝条件和文件操作边界，不下载或保存理光固件。含真实官方输入的集成测试通过 `GRD3_STOCK` 在本地运行，缺少该输入时会明确标记为跳过。详见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

v0.1.0 发布前在 Linux / Python 3.12.3 上运行了 19 项测试，全部通过，其中 6 项使用机主本地保存的官方固件进行集成验证。CLI 构建后再次验证，并将生成的 GLAUNCH3 与实际试刷文件逐字节比较，结果一致。跨平台 CI 的实时结果见仓库 Actions；CI 本身不包含这 6 项真实固件测试。
